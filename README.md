## Responsibilities of this repository

`ai-sdk-python` is the official OpenStrata developer library for the **Python
ecosystem** (published to PyPI as `openstrata-sdk`, import `openstrata_sdk`). It
is a three-layer lightweight "client + builder + extension port" library — **not**
a deployable service. It lets Python applications (FastAPI, notebooks, scripts,
ML pipelines) embed a conversational Agent/Client and reach platform runtime
capabilities (Gateway, Agent runtime, tool registration, memory, RAG, cache,
observability) with minimal intrusion.

- **Exposes/depends on 15 platform SPI ports** (see `docs/ARCH.md` §3 / `docs/DESIGN.md` §6),
  defined as `typing.Protocol` in `openstrata_sdk.domain`: `Gateway`, `AgentRuntime`,
  `LLMProvider`, `VectorStore`, `Cache`, `Auth`, `Tracing`, `RAG`, `LowCode`,
  `Workflow`, `Sandbox`, `CICD`, `MultiTenancy`, `MLOps`, `Eval` — all framework-free.
- **First-class objects**: `Client` (`api`), `AgentSpec`/`Agent` (`domain`/`application`),
  `Tool`, `Session`, `Retriever` (`domain`).
- **Default adapters** (all stdlib-only, offline/test-friendly) live in
  `openstrata_sdk.infrastructure`: echo `LLMProvider`, in-memory `Cache`/`VectorStore`
  (cosine search), `LocalAgentRuntime`/`LocalAuth`, `NoOpTracing`, and logging
  `RAG`/`Gateway`/`Workflow`/`Sandbox`/`CICD`/`MLOps`/`Eval`/`MultiTenancy`/`LowCode`.
  `HTTPGateway` is a real httpx-backed adapter (lazy-imported) for production.
- **External components**: `pydantic>=2` (value types / `AgentSpec`), `httpx`
  (production gateway only), `opentelemetry-api` (tracing baseline). No web
  framework is forced — hosts embed it freely.

## Local development

```bash
# Create a venv and install runtime + dev deps (Python 3.11+)
python3 -m venv .venv && .venv/bin/pip install pydantic httpx opentelemetry-api pytest

# Run the test suite (offline — no network, stdlib default adapters)
.venv/bin/python -m pytest -q          # pythonpath=src is set in pyproject.toml

# Run the offline demo
PYTHONPATH=src .venv/bin/python -m app.demo
```

Configuration is loaded by `Client.from_env()` (or `Config.load(Config.from_env(),
Config.from_file("infrastructure/config/openstrata.toml"))`) with priority:
explicit > env (`OPENSTRATA_*`) > TOML fragment > defaults. See `docs/DESIGN.md` §7.

### Quickstart

```python
from openstrata_sdk import Client, AgentSpec, ModelBinding, ObjectSchema, Guardrails

client = Client.from_env()

spec = (AgentSpec.builder("customer-service-v2")
        .tenant("tenant-b")
        .model_binding(ModelBinding(preferred="cloud-qwen-max"))
        .input_schema(ObjectSchema("query", "string"))
        .output_schema(ObjectSchema("answer", "string"))
        .guardrails(Guardrails(checks=["injection_scan", "pii_scan"]))
        .build())

handle = client.agent_runtime.load(spec)
out = client.agent_runtime.run(handle, {"query": "Where is my order?"})
print(out["output"])
```
